## French → English glossary (from HANDOFF §5)

The thesis is in French. These technical terms are kept as-is in quotes and translated as follows:

| French | English |
|---|---|
| PHMA (*plus hautes mers astronomiques*) | HAT (highest astronomical tide) |
| *haut de plage* / *bas de plage* | upper beach / lower beach |
| *pied de dune* | dune toe |
| *engraissée* | accreted ("fat") beach |
| *surcote* | (storm) surge |
| *jet de rive* | swash |
| *levé* | (topographic) survey |
| ZH (*zéro hydrographique*) | chart datum |
| NM (*niveau moyen*) | mean sea level |
| TPTE (*Tout le Profil – Tempêtes Érosives*) | whole profile, erosive storms only (thesis model) |
| PPT (*Profil Pré-Tempête*) | pre-storm profile (thesis model) |
